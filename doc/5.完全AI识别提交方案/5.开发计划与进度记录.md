# 完全 AI 识别提交 - 开发计划与进度记录

## 一、开发计划概览

基于 [方案B-MVP设计书](./2.方案B-MVP设计书.md)、[轻量Agent构建原理说明](./3.轻量Agent构建原理说明.md)、[自建实现路径与开源方案](./4.自建实现路径与开源方案.md)、[收敛方案-程序主控](./6.收敛方案-程序主控.md) 制定以下开发计划。

### 1.1 目标

在 website-commiter-extention 内自建「轻量 Agent」：**AI 仅生成评论**；**Snapshot 用于程序定位**；**程序主控**完成元素映射与固定顺序执行（fill → check → click），解决弹窗、无常规提交按钮、新站无缓存等问题。**不依赖 AIPex 与 MCP**。

### 1.2 开发阶段


| 阶段          | 内容                                   | 预估工作量 |
| ----------- | ------------------------------------ | ----- |
| **Phase 1** | 感知层：Snapshot 采集（DOM 遍历、UID 分配、文本格式化） | 1 天   |
| **Phase 2** | 行动层：按 UID 执行 click/fill              | 0.5 天 |
| **Phase 3** | 控制层 + 协议层：多轮调度、LLM 请求/解析、超时与终止       | 1 天   |
| **Phase 4** | 集成：manifest、background 接入、消息协议       | 0.5 天 |
| **Phase 5** | 验证：单轮 E2E、多轮闭环、超时测试                  | 0.5 天 |


**合计**：约 3.5 天

## 二、详细任务分解

### Phase 1：感知层（content/fullAiContent.js - Snapshot 部分）

- DOM 遍历：从 document.body 递归，过滤 script/style/hidden 等
- 可交互节点识别：button/input/textarea/select/a、role、cursor:pointer
- UID 分配：`data-wce-nodeid`，格式 `wce-${Date.now().toString(36)}-${cnt}`
- 树结构构建：SnapshotNode { id, role, name, value, children }
- 文本格式化：每行 `[depth] uid=xxx role "name" <tagName> [value="..."][disabled]`
- 消息监听：`fullAiTakeSnapshot` → 返回 `{ snapshotText, snapshotResult }`
- 长度控制：name/value 截断 160 字符，总文本上限 12k

### Phase 2：行动层（content/fullAiContent.js - Execute 部分）

- 消息监听：`fullAiExecute`，解析 `steps: [{ op, uid, value? }]`
- UID 查找：`querySelector('[data-wce-nodeid="' + cssEscape(uid) + '"]')`
- click：scrollIntoView + dispatchEvent(mousedown/mouseup/click)
- fill：element.value = value + dispatchEvent(input/change)
- 响应格式：`{ success, results: [{ op, uid, ok, error? }] }`

### Phase 3：控制层 + 协议层（lib/fullAiAgent.js）

- 单轮逻辑：取 Snapshot → 拼 prompt → 调 LLM → 解析 JSON → 下发执行
- 多轮循环：while (!done && round < MAX_TURNS && !timeout)
- 终止条件：done、MAX_TURNS(10)、ROUND_TIMEOUT(45s)、TASK_TIMEOUT(120s)
- Prompt 模板：任务描述 + siteUrl + generatedComment + 轮次 + snapshotText + formHint
- 响应解析：抽取 JSON、校验 steps、兼容 markdown 包裹
- **混合策略**：任务开始时调用 fullAiPrepareForComment 预滚动+表单检测；第 2 轮起若有 formRootSelector 则 Snapshot 限定表单范围

### Phase 4：集成

- manifest.json：content_scripts 添加 fullAiContent.js
- background.js：处理 `fullAiRunTask` 消息，调用 fullAiAgent
- 入口：Side Panel Blog 面板「使用完全 AI 识别」复选框，勾选后调用 fullAiRunTask

### Phase 5：验证

- Snapshot：在 Blog 页能返回含 button/link/textbox 的 snapshotText
- 执行：给定 uid 能正确 click/fill
- 单轮 E2E：mock LLM 响应验证整条链路
- 多轮：2～3 轮场景能按 done/超时正确终止
