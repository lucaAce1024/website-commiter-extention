# 标记外链逻辑修改方案 - 可行性报告

## 一、需求概述

### 1.1 当前实现

点击「遍历检测可评论站点」按钮时：

- 风险：遍历 `traverseBacklinkList` 中的每个 URL
- 检测页面是否为 Blog 评论站（`isBlogCommentSite`）
- 是否需要登录（`requiresLogin`)
- 将可评论的站点存入 `batch.discoveredSites` 数组
- **同时**调用 `appendDiscoveredSitesToFeishu` 写入到**第二个飞书表格**（配置项: `exploreSheetToken`/`exploreSheetId`）

### 1.2 目标需求

- **不再**将检测结果写入第二个飞书表格
- **改为**在第一个 Ahrefs 反链飞书表格（配置项: `ahrefsSheetToken`/`ahrefsSheetId`）中新增三个字段
  1. **是否为 Blog Comment 评论外链** - 是/否
  2. **是否需要登录** - 是/否
  3. **是否是导航站** - 是/否
  (*注：当前代码未实现导航站检测逻辑，需新增)

通过 URL 匹配，将检测结果**回写**到对应的行

## 二、飞书 API 可行性分析

### 2.1 相关 API

根据飞书 API 文档 (`doc/8.feishu apidoc/飞书api.md`) 核心操作需要以下接口：

#### 2.1.1 查找单元格 API

```
POST /sheets/v3/spreadsheets/{spreadsheet_token}/sheets/{sheet_id}/find
```

**请求示例**:

```json
{
  "find_condition": {
    "range": "Sheet1!A:A",
    "match_case": false,
    "match_entire_cell": true,
    "search_by_regex": false
  },
  "find": "https://example.com/page"
}
```

**返回**:

```json
{
  "code": 0,
  "data": {
    "find_result": {
      "matched_cells": ["A5", "A10"]
    }
  }
}
```

#### 2.1.2 写入单元格 API

```
PUT /sheets/v3/spreadsheets/{spreadsheet_token}/values
```

**请求示例**:

```json
{
  "valueRange": {
    "range": "Sheet1!E5",
    "values": [["是", "否", "否"]]
  }
}
```

*注：假设 E 列为 "是否为 Blog Comment 评论外链", F 列为 "是否需要登录", G 列为 "是否是导航站"*

### 2.2 实现步骤

1. **获取 access_token**
  ```js
   const token = await getFeishuAccessToken(config.appId, config.appSecret);
  ```
2. **查找 URL 对应的行号**
  ```js
   const findResponse = await fetch(
     `https://open.feishu.cn/open-apis/sheets/v3/spreadsheets/${config.ahrefsSheetToken}/sheets/${config.ahrefsSheetId}/find`,
     {
       method: 'POST',
       headers: {
         'Authorization': `Bearer ${token}`,
         'Content-Type': 'application/json'
       },
       body: JSON.stringify({
         find_condition: {
           range: `${config.ahrefsSheetId}!A:A`,
           match_case: false,
           match_entire_cell: true
         },
         find: normalizedUrl
       })
     }
   );
   const matchedCells = findResponse.data?.find_result?.matched_cells || [];
  ```
3. **根据行号更新对应列**
  ```js
   // 假设找到的单元格为 A5，B5、C5
   // E 列为 "是否为 Blog Comment 评论外链"， F 列为 "是否需要登录"， G 列为 "是否是导航站"
   const rowNumbers = matchedCells.map(cell => parseInt(cell.replace(/[A-Z]/, '')));

   // 更新每个单元格
   for (const rowNum of rowNumbers) {
     const updateResponse = await fetch(
       `https://open.feishu.cn/open-apis/sheets/v3/spreadsheets/${config.ahrefsSheetToken}/values`,
       {
         method: 'PUT',
         headers: {
           'Authorization': `Bearer ${token}`,
           'Content-Type': 'application/json'
           },
         body: JSON.stringify({
             valueRange: {
               range: `${config.ahrefsSheetId}!E${rowNumber}`,
               values: [[isBlogComment, requiresLogin, isNavigationSite]]
             }
           }
         }
       );
     }
   }
  ```

### 2.3 选列位置

需要确定三个新增字段在飞书表格中的位置。可以:

- **固定位置**：E、F、G 列（固定在表格末尾）
- **动态位置**：在运行时通过 API 查询表格元数据获取最后使用的列

建议使用固定位置以简化实现。

**默认列位置：K、L、M、N 列**

| 列 | 字段名 |

## 三、风险与注意事项


| 风险点           | 说明                         | 缓解措施                        |
| ------------- | -------------------------- | --------------------------- |
| **URL 格式不一致** | 飞书表格中的 URL 与检测的 URL 格式可能不同 | 统一使用 `normalizeUrl` 标准化后再匹配 |
| **API 限流**    | 飞书 API 有调用频率限制             | 增加调用间隔，或批量处理                |
| **表格结构变化**    | 用户修改表格结构导致列号失效             | 提供列号配置项，或通过列名查找             |
| **网络超时**      | 网络请求可能超时                   | 增加重试机制                      |
| **并发写入**      | 多个标签页同时写入可能导致数据覆盖          | 使用乐观锁或队列机制                  |

## 五、导航站检测规则增强（新增）

### 5.1 强判定规则

以下条件满足**任一**即判定为导航站（无需计分）：

#### 5.1.1 Navbar 包含 Submit 按钮

检测导航栏（`<nav>`, `<header>`, `.navbar`, `#navbar`, `[role="navigation"]`）中是否包含提交相关按钮。

**多语言提交按钮关键词：**

| 语言 | 关键词 |
|------|--------|
| 英语 | `submit`, `add url`, `add site`, `suggest`, `submit site`, `submit url`, `add your site` |
| 中文 | `提交`, `收录`, `提交网站`, `添加网址`, `网站提交`, `网址收录` |
| 德语 | `einreichen`, `hinzufügen`, `vorschlagen` |
| 法语 | `soumettre`, `ajouter`, `proposer` |
| 西班牙语 | `enviar`, `añadir`, `sugerir` |
| 意大利语 | `invia`, `aggiungi`, `suggerisci` |
| 日语 | `送信`, `追加`, `提案` |
| 韩语 | `제출`, `추가`, `제안` |

#### 5.1.2 URL 路径包含特定片段

使用正则精确匹配路径（需**完整路径片段**，非子串匹配）：

| 路径模式 | 说明 |
|----------|------|
| `/tool/` | 工具目录页 |
| `/tools/` | 工具列表页 |
| `/directory/` | 目录页 |
| `/directories/` | 目录列表页 |

**正则模式：**
```javascript
/(?:^|\/)(?:tool|tools|directory|directories)(?:\/|$)/i
```

**注意：** 必须是完整路径片段，例如：
- ✅ `https://example.com/tools/submit` - 匹配
- ✅ `https://example.com/directory/category` - 匹配
- ❌ `https://example.com/mytools/page` - 不匹配（`mytools` 不是完整片段）
- ❌ `https://example.com/directorieslist` - 不匹配（`directorieslist` 不是完整片段）

### 5.2 判定优先级

```
1. 强判定规则（Navbar Submit 按钮 或 URL 路径）
   ↓ 命中任一 → 直接返回 true
   ↓ 未命中
2. 计分规则（阈值 5 分）
   - URL 路径特征 (+2)
   - 标题命中关键词 (+3)
   - 描述命中关键词 (+2)
   - 页面内容关键词 (+1~2)
   - 提交表单 (+3)
   - 链接密集 (+1~2)
   ↓
3. 总分 ≥ 5 → 返回 true，否则返回 false
```

### 5.3 实现示例

```javascript
function isNavigationSite(url, html) {
  // ====== 强判定规则 ======

  // 强判定 1：Navbar submit 按钮
  const navbarSelectors = ['nav', 'header', '.navbar', '#navbar', '[role="navigation"]'];
  const submitKeywords = [
    'submit', 'add url', 'add site', 'suggest', 'submit site', 'submit url', 'add your site',
    '提交', '收录', '提交网站', '添加网址', '网站提交', '网址收录',
    'einreichen', 'hinzufügen', 'vorschlagen',
    'soumettre', 'ajouter', 'proposer',
    'enviar', 'añadir', 'sugerir',
    'invia', 'aggiungi', 'suggerisci',
    '送信', '追加', '提案',
    '제출', '추가', '제안'
  ];

  // 尝试从 HTML 中提取 navbar 区域
  for (const selector of ['<nav[^>]*>', '<header[^>]*>', '<[^>]*class=["\'][^"\']*navbar[^"\']*["\']', '<[^>]*role=["\']navigation["\']']) {
    const regex = new RegExp(selector + '[\\s\\S]*?<\\/[^>]+>', 'gi');
    const matches = html.match(regex);
    if (matches) {
      for (const match of matches) {
        const text = match.toLowerCase();
        for (const keyword of submitKeywords) {
          if (text.includes(keyword.toLowerCase())) {
            return true; // 强判定命中
          }
        }
      }
    }
  }

  // 强判定 2：URL 路径包含 /tool/ /tools/ /directory/ /directories/
  try {
    const urlPath = new URL(url).pathname;
    const navPathPattern = /(?:^|\/)(?:tool|tools|directory|directories)(?:\/|$)/i;
    if (navPathPattern.test(urlPath)) {
      return true; // 强判定命中
    }
  } catch (e) {}

  // ====== 计分规则 ======

}
```
