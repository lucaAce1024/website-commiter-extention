# Blog 评论功能测试用例

本文档供验证「单页 Blog 评论」与「批量提交」功能，按步骤执行并核对预期结果。

---

## 前置条件

- Chrome 已加载本扩展（开发者模式 → 加载已解压的扩展程序）。
- 在 **设置** 中至少添加一个 **站点档案**（含：网站名称、URL、联系邮箱）。
- 建议在设置中配置 **LLM API**（智谱 GLM / OpenAI 等），以便「生成评论」与「评论表单 AI 识别」可用；未配置时仍可使用关键词匹配识别评论表单。

---

## 第一阶段：单页 Blog 评论功能

### 用例 1.1：Popup 模式切换与 Blog 评论 Tab

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击扩展图标打开 Popup | 默认显示「导航站」模式，有「当前站点」「当前页面」「自动识别并填充」等 |
| 2 | 点击顶部「Blog 评论」Tab | 切换为 Blog 评论模式：显示「当前站点」、当前页域名、评论表单状态、「生成评论并填充」「验证本次提交」、快捷操作「Blog 评论站点列表」 |
| 3 | 再点击「导航站」Tab | 恢复为导航站模式 |

### 用例 1.2：评论表单识别状态

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开一个**带评论表单**的博客文章页（如 WordPress 评论、常见博客主题评论区） | 页面加载完成 |
| 2 | 在 Popup 中切换到「Blog 评论」Tab，并选择当前站点 | 「评论表单」显示为「已识别」或「识别中...」后变为「已识别」；「可填字段」显示为 N 个字段（N≥1） |
| 3 | 若页面含 reCAPTCHA 或算术验证等 | 出现提示「检测到验证项，将暂停自动提交」 |

### 用例 1.3：生成评论并填充（无验证码）

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在无验证码的博客评论页，选择当前站点，点击「生成评论并填充」 | 按钮先变为「生成中...」→「识别表单...」→「填充中...」 |
| 2 | 等待流程结束 | 提示「已填充 N 个字段」；若未检测到验证项，提示包含「已自动点击提交」；页面评论框中 Comment、Name、Email、Website 已被填入当前站点信息，评论内容为根据当前页 title/description 生成的英文短评（约 200 字内） |
| 3 | 若配置了 LLM 且识别成功 | 提交按钮被自动点击（无验证时）；约 4 秒后可能弹出「验证成功：已在页面中找到您的站点链接」或「未检测到您的站点链接」 |

### 用例 1.4：有验证码时仅填充不提交

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在**带算术/图形验证**的博客评论页，选择当前站点，点击「生成评论并填充」 | 流程同上，填充完成 |
| 2 | 观察提示与页面 | 提示中包含「检测到验证项，请手动完成验证后点击提交」；**不会**自动点击提交按钮；表单已被填充，用户可手动完成验证后点击提交 |

### 用例 1.5：验证本次提交

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在已提交评论且评论区已展示含「本站链接」的页面，点击「验证本次提交」 | 扩展在页面中查找指向当前站点 URL 的可点击链接 |
| 2 | 若找到 | 提示「验证成功：已在页面中找到您的站点链接」 |
| 3 | 若未找到（如评论未通过审核、链接未展示） | 提示「未在页面中检测到您的站点链接，请确认评论是否已发布」 |

### 用例 1.6：清除本页评论识别缓存

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在已识别过评论表单的页面，点击「清除本页评论识别缓存」 | 提示「已清除本页评论缓存」；评论表单状态可变为「未识别」或需再次识别 |
| 2 | 再次点击「生成评论并填充」 | 会重新识别评论表单后再填充 |

## 第二阶段：批量提交功能

### 用例 2.1：Blog 评论站点列表管理

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 打开扩展 **设置页**（Options），切换到「Blog 评论列表」Tab | 显示「Blog 评论站点列表」、添加/导入按钮 |
| 2 | 点击「添加评论页」 | 弹窗：名称、评论页 URL；保存后列表中出现一条记录，可打开链接、编辑、删除 |
| 3 | 点击「导入」并选择包含 `blogCommentSites` 或 `[{ "name": "xxx", "url": "https://..." }]` 的 JSON | 列表合并新记录，提示导入条数 |

### 用例 2.2：按列表批量打开并执行单页流程（手动步进）

当前实现为「单页生成+识别+填充+提交」；批量可理解为：用户从「Blog 评论站点列表」中逐个打开 URL，在每个标签页中点击 Popup 的「生成评论并填充」，从而顺序完成多站评论。

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在设置中添加 2～3 条 Blog 评论页 URL（建议含 1 个带验证码的站） | 列表中有多条 |
| 2 | 点击某条的「打开」链接，在新标签页打开该博客评论页 | 新标签页打开对应 URL |
| 3 | 在该标签页打开 Popup，切到 Blog 评论，选择站点，点击「生成评论并填充」 | 按单页流程：生成评论 → 识别表单 → 填充；有验证则仅填充并提示手动提交，无验证则自动点击提交并可验证 |
| 4 | 对下一个 URL 重复 2～3 | 每站独立执行单页流程，互不影响 |

### 用例 2.3：批量结果汇总（设计预期）

若后续实现「批量提交」自动化（按列表依次打开、执行、记录结果），预期行为：

- 每个 URL 执行：打开 → 注入/激活 Content Script → 生成评论 → 识别评论表单 → 检测验证项；有验证则仅填充并记录「需人工验证」，无验证则填充并点击提交，再执行验证环节。
- 汇总：验证成功数、需人工验证数、验证未通过/失败数。

当前版本以「单页 + 手动切换标签页」为主，列表主要用于管理待评论 URL 与快速打开。

## 检查清单（回归用）

- [ ] Popup 有「导航站 / Blog 评论」Tab 切换，Blog 评论仅显示评论相关 UI
- [ ] 评论表单能识别（缓存 / AI / 关键词），可填字段数正确
- [ ] 防 Spam 检测：有验证时仅填充、不点提交，并提示
- [ ] 无验证时：填充后自动点击提交按钮
- [ ] 提交后验证：能根据「本站 URL」在页面中查找可点击链接并给出成功/未找到提示
- [ ] Options 中「Blog 评论列表」可增删改、导入
- [ ] 备份/恢复包含 `blogCommentSites` 与评论相关缓存

## 附录：测试用 JSON 导入示例

**Blog 评论站点列表导入**（保存为 `blog-sites.json`）：

```json
[
  { "name": "测试博客 A", "url": "https://example.com/blog/post-1/#comments" },
  { "name": "测试博客 B", "url": "https://another-site.com/article/123/" }
]
```

或带键名：

```json
{
  "blogCommentSites": [
    { "name": "测试博客 A", "url": "https://example.com/blog/post-1/#comments" }
  ]
}
```

导入时扩展会为每条生成 `id` 与时间戳，无需在 JSON 中提供。
