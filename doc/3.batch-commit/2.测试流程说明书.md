## 阶段二：批量提交与飞书集成测试

### 测试前准备

#### 准备飞书多维表格
1. 在飞书中创建一个多维表格（Bitable）
2. 表格需包含以下列：
   | 列名 | 类型 | 说明 |
   |------|------|------|
   | 外链 URL | 文本 | 待提交的页面 URL |
   | 类型 | 单选 | Blog 评论站 / 导航站 / 其他 |
   | 提交状态 | 文本 | 待提交 / 提交中 / 检测成功 / 检测失败 / 需人工验证 |
   | 最后更新时间 | 文本 | 如 2025/01/01 12:00:00 |
   | 备注 | 文本 | 可选 |

3. 添加 3-5 条测试数据（URL 为真实的 Blog 评论页面）

#### 获取飞书凭证
1. 在飞书开放平台创建应用
2. 获取 App ID 和 App Secret
3. 配置应用权限：`bitable:app`、`bitable:app_record`
4. 获取多维表格的 App Token 和 Table ID（从 URL 或设置中获取）

## 常见问题排查

### 问题 1：Side Panel 打开后立即关闭
- **原因**：manifest.json 中同时配置了 popup 和 side_panel
- **解决**：检查 manifest.json，确保配置正确

### 问题 2：评论生成失败
- **原因**：LLM 未配置或 API Key 无效
- **解决**：检查 options 页面的 LLM 配置

### 问题 3：飞书同步失败
- **原因**：凭证错误或权限不足
- **解决**：
  1. 检查 App ID、App Secret 是否正确
  2. 检查应用是否有多维表格权限
  3. 检查 App Token、Table ID 是否正确

### 问题 4：批量提交卡住不动
- **原因**：页面加载超时或 content script 未注入
- **解决**：
  1. 检查目标 URL 是否可访问
  2. 检查 content script 是否正确注入
  3. 查看浏览器控制台是否有错误

### 问题 5：状态未回写到飞书
- **原因**：API 调用失败或字段名不匹配
- **解决**：
  1. 检查飞书表格列名是否与代码一致
  2. 查看控制台日志确认 API 响应
