# 外链提交助手

Chrome 浏览器插件，自动识别并填充导航站收录表单，提升网站提交效率。

## 运行环境

- Chrome 扩展 Manifest V3
- 需在 Chrome 扩展商店或开发者模式下加载使用

## 已实现功能

### 1. 导航站表单自动识别与填充

- **自动识别表单**：打开导航站提交页面时，自动检测并解析表单结构
- **一键填充**：点击「自动识别并填充」即可将当前选中的站点信息填入表单
- **按字段填充**：识别完成后支持仅填充单个字段（如只填网站 URL）
- **识别方式**：
  - **关键词匹配**：基于 name、label、placeholder、aria-label 等属性，支持中英文
  - **AI 智能识别**（可选）：需在设置中配置 GLM / OpenAI / Groq 等兼容 API，提高复杂表单识别准确率
- **识别缓存**：按「域名 + 路径」缓存字段映射，同一页面再次访问时直接复用；支持「清除本页缓存」后重新识别

### 2. 支持的表单控件类型

| 控件类型 | 说明 |
|----------|------|
| 原生 input / textarea / select | 文本、URL、邮箱、文件上传、下拉选择 |
| 自定义下拉 (Headless UI 等) | Categories、Tags、Pricing 等 combobox / listbox |
| 富文本编辑器 | contenteditable、ProseMirror、TipTap、Quill |
| Markdown 编辑器 | CodeMirror、SimpleMDE、EasyMDE |

### 3. 站点管理

- **多站点档案**：可维护多个待提交网站的完整信息
- **支持字段**：网站名称、URL、联系邮箱、分类、标签、定价、标语、简短描述、详细描述、Logo、界面截图
- **Logo / 界面截图**：支持 URL 输入或本地上传；超过 1MB 的图片会自动压缩
- **分类智能匹配**：内置中英文分类同义词映射，便于与各导航站下拉选项对应

### 4. 导航站列表

- **添加 / 编辑 / 删除** 导航站及提交页面 URL
- **导入**：支持从 JSON 批量导入导航站
- **快速打开**：从列表直接打开提交页面

### 5. 右键菜单

在任意输入框（包括富文本区域）内右键，可选择「填充单个字段」，将当前站点的对应字段填入该控件。

### 6. 设置

- **LLM 配置**：可选配置 OpenAI、智谱 GLM、Groq 或自定义 API 端点
- **测试连接**：验证 API Key 与端点是否可用
- **自动提交**：可选开启填充完成后自动点击提交（慎用，建议仅在熟悉站点使用）

### 7. 备份与恢复

- **创建备份**：导出站点、导航站、识别缓存、提交记录为 JSON
- **恢复备份**：支持「完全替换」或「合并」现有数据

### 8. 其他能力

- **验证码检测**：填充后若检测到验证码，会提示用户手动完成
- **提交记录**：记录每次填充的站点、域名、时间与状态
- **识别与填充**：管理各域名下的字段映射缓存，支持清除单条或全部

## 安装与使用

1. 克隆或下载本项目
2. 打开 Chrome → 扩展程序 → 管理扩展程序 → 开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择项目根目录
4. 在扩展页添加站点档案、导航站列表
5. 打开目标导航站提交页，点击插件图标，选择当前站点后点击「自动识别并填充」

## 飞书集成

支持从飞书多维表格同步待提交的外链记录，实现批量提交管理。

### 飞书配置

在设置页面配置以下飞书凭证：
- **App ID**：飞书应用的 App ID
- **App Secret**：飞书应用的 App Secret
- **App Token**：多维表格的 App Token（从多维表格 URL 获取）
- **Table ID**：数据表的 Table ID（从多维表格 URL 获取）

### 多维表格字段要求

在飞书多维表格中创建数据表时，需要包含以下字段（所有字段类型均为**文本**）：

| 字段名 | 字段类型 | 是否必填 | 允许值 |
|--------|----------|----------|--------|
| `外链 URL` | 文本 | **必填** | 有效的网站 URL |
| `类型` | 文本 | **必填** | `导航站`、`Blog评论站`、`其他` |
| `提交状态` | 文本 | **必填** | `待提交`、`提交中`、`检测成功`、`检测失败`、`需人工验证`、`识别失败`、`超时` |
| `备注` | 文本 | 可选 | 任意文本 |

> **注意**：
> - 字段名支持中英文，代码会依次尝试匹配 `外链 URL`、`url`、`link_url` 等字段名
> - URL 字段为空或格式错误的记录会被跳过，并在同步时提示字段问题
> - 类型、提交状态字段必须使用上表中的允许值，否则可能影响筛选功能

### 同步流程

1. 点击侧边栏的「从飞书同步」按钮
2. 系统会自动获取飞书多维表格中的记录
3. 验证字段格式，过滤无效记录
4. 如果存在字段问题，会在状态栏显示警告信息
5. 有效的记录会显示在批量提交列表中

## 外链采集 · 自动模式（侧栏「外链采集 / Explore」）

在侧栏切换到外链采集模式，可使用 **自动采集**：自动完成「提取域名 → WHOIS 筛选 → Ahrefs 拉取反链 → 遍历检测可评论站点」，可选 **循环模式** 将发现的 Blog 站作为下一轮种子。

### 自动模式使用步骤

1. **打开一个博客评论页面**（或已能从评论区提取到目标域名的页面）。
2. 在侧栏 **外链采集** 中配置好 Ahrefs / 飞书（如需写入「外链采集 - Ahrefs 反链」表）后，点击 **开始自动采集**。
3. **等待采集完成**；侧栏 **实时日志** 会滚动显示进度（仅保留最近 50 条），包括：
   - **步骤3**：域名处理进度 `当前/总数`、当前域名；
   - **步骤4**：待检测 URL 列表进度 `当前/总数`。
4. 在 **飞书** 中打开对应表格，按需要 **筛选** 记录，获取 **Blog 评论站** 清单（及反链、标记字段等）。
5. **循环模式**（若已勾选）：任务会将本轮检测到的 **可评论 Blog 站点** 作为下一批次的输入域名，继续跑新一轮自动采集，直到达到最大深度、无新站点或你手动停止。

### 循环模式说明

- 开启 **循环模式** 后，每一轮结束会把 **「遍历检测」阶段识别为可评论的站点** 汇总为下一轮要处理的域名列表（受 `LOOP_CONFIG` 中最大深度、每轮站点数上限等约束）。
- 若某轮 **没有发现新的可评论站点**，循环可能按配置自动结束。
- 单次模式仅执行一轮四个步骤后结束。

### 进度与变更（开发记录）

- **自动采集步骤4**：已改为调用与手动「遍历检测」相同的 `runTraverseLoopOnly`，修复「遍历检测函数不可用」导致步骤 4 不执行的问题。
- **实时日志**：最多保留 **50** 条，时间正序展示；视口高度约 **10 条**单行日志，更早记录在 **同一视口内向上滚动** 查看；新日志写入时 **自动滚到底**。
- **状态栏**：步骤文案与左侧「步骤」标签去重（显示为 `1/4：…` 形式）。

### 设置页「缓存管理 → 外链采集 · 任务状态」

- 自动采集与外链批次在**扩展侧栏**中执行，**不是**独立后台进程；关闭侧栏后当前 JS 会停止，但 `chrome.storage.local` 可能仍保留上次保存的 `autoCollectTask` / `backlinkExplorationBatches`。
- 在 **设置 → 缓存管理** 顶部可查看上述存储的**快照**（任务状态、待处理批次数、非 idle 批次列表等）；点「刷新缓存」会更新。
- 侧栏 **外链采集 → 重置状态**：清空 `backlinkExplorationBatches` 与 `autoCollectTask`、重置侧栏进度与 UI，**不删除 Ahrefs 域名缓存**，便于在保留反链缓存的前提下重新开始采集；会**暂时禁止**自动采集任务写回 storage，避免收尾循环覆盖清空（下次「开始自动采集」或恢复任务时重新允许写入）。
- 侧栏 **外链采集 → 清除缓存**：**仅**清除 Ahrefs 元数据（`ahrefs_domain_cache`）与 Background IndexedDB 中的反链缓存，**不**清空外链批次与自动采集任务。

### 设置页「Ahrefs 域名缓存」说明

- **`ahrefs_domain_cache` 不是 IndexedDB**：它存在 **`chrome.storage.local`**，且**只存元数据**（域名、日期、`urlCount`/`backlinkCount`、DR 等），不存整表反链，避免占用过大。
- **真正用于跳过 API 的缓存**：在 Background 的 **IndexedDB**（`ahrefs_cache_idb_v1`），含完整 `urlFromList`/`backlinks`（有单域与总域名数上限），**TTL 约 7 天**，与设置页「过期」提示对齐。
- 成功拉取或命中 IDB 后，侧栏会**同步轻量元数据**到 `ahrefs_domain_cache` 供列表展示；「清除 Ahrefs 缓存」会同时清空 **storage + IndexedDB**。
